Product and Engineering Brief

FocusMatrix

Eisenhower Productivity & Task Management System

A local-first productivity workspace for turning urgency and importance into focused action.

Team briefing · September 2026

Executive Summary

FocusMatrix helps users capture tasks, classify them through the Eisenhower Matrix, schedule due dates and reminders, and work from a calm dashboard that runs locally.

Implemented now
  • Responsive dashboard and navigation
  • Task creation with urgency and importance
  • Automatic quadrant classification
  • Complete and reopen workflows
  • Due dates and recurring local reminders
Runtime options
  • Browser-based Vite application
  • Portable Windows Electron executable
  • Offline IndexedDB task storage
  • Optional Supabase authentication
  • DigitalOcean static hosting path
Important boundary: authentication is optional and currently does not synchronize tasks. Task data remains local to the browser or Electron profile.

Current interactions

  • Create tasks from the dashboard or any task-aware view.
  • Set the due date, with today's date selected by default.
  • Enable one-time, daily, weekly, or monthly reminders.
  • Complete tasks from the matrix or task list.
  • Reopen completed tasks from Closed tasks.
  • Edit the local profile display name from the avatar.
  • Move between Dashboard, Matrix, Tasks, Calendar, and Analytics views.

Privacy and Data Safety

  • No task data is sent to the hosted server.
  • Tasks are stored in the local focus-matrix IndexedDB database.
  • Profile names are stored locally in browser storage.
  • Authentication uses only browser-safe Supabase configuration.
  • Service-role keys and DigitalOcean tokens must remain in secrets.
  • Electron disables renderer Node integration and enables context isolation.
  • No analytics, advertising, or tracking scripts are configured.
Operational limitation: local reminders run while FocusMatrix is open. Background operating-system notifications, backup/restore, export/import, and cloud task sync are not implemented yet.

CI/CD

Pull requests run dependency installation, lint, and production build checks. Pushes to main additionally build an immutable Docker image tagged with the commit SHA, push it to DigitalOcean Container Registry, and update App Platform.

Required GitHub configuration includes DIGITALOCEAN_ACCESS_TOKEN, DOCR_REGISTRY, DO_APP_ID, and optional Supabase secrets.
